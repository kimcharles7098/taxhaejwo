TAX해줘 운영자는 상담 문의에 답변하기 위해 아래와 같이 개인정보를 처리합니다. 문의: mongdingding@gmail.com

계산기에 입력한 수입·경비·급여·근로시간 등은 브라우저에서 계산하며 상담 메일에 넣지 않습니다. ‘문의 보내기’를 선택할 때 상담 폼에 직접 적은 정보만 전송합니다.

1. 처리 목적과 수집 항목

  • 목적: 상담 접수, 문의 확인과 답변, 필요한 경우 전화 연락.
  • 필수 항목: 문의 목적, 답변받을 이메일, 문의 내용, 전송 동의 여부.
  • 선택 항목: 전화번호. 입력하지 않아도 이메일 상담을 이용할 수 있습니다.
  • 접속 IP, 접속 시각, 요청 경로 등의 기술 정보는 호스팅 서비스가 접속 처리·보안·반복 요청 차단을 위해 처리할 수 있습니다.

주민등록번호, 금융계좌, 건강정보 등 상담 접수에 필요하지 않은 민감한 정보는 입력하지 마세요.

2. 보관과 삭제

상담 연락처와 내용은 운영자 Gmail 메일함에 보관하며, 상담 종료 후 30일 이내 운영자가 관련 메일을 직접 삭제합니다. Gmail 휴지통에 남지 않도록 영구 삭제합니다. 자동 삭제 기능은 제공하지 않습니다. 법령상 별도 보관 의무가 있는 경우 그 근거와 기간을 구분해 보관합니다. 삭제를 원하면 위 이메일로 요청할 수 있습니다.

서버 애플리케이션에는 별도의 상담 데이터베이스를 두지 않으며 문의 본문이나 연락처를 애플리케이션 로그로 기록하지 않습니다. 호스팅 서비스의 기술·보안 로그에는 해당 서비스의 보관 정책이 적용됩니다.

3. 메일 전송과 외부 서비스 처리

상담 접수는 Vercel의 서버 함수를 거쳐 Gmail API로 운영자 메일함에 전달됩니다. 광고·마케팅 목적으로 사용하거나 판매하지 않습니다.

  • Vercel Inc.: 웹사이트 호스팅, 상담 요청 중계, 접속 보안. 상담 폼의 항목과 접속 기술 정보를 처리합니다. 상담 서버 함수는 미국(iad1)에서 실행됩니다. 접수 시 HTTPS로 전송하며 요청 처리와 서비스의 기술·보안 로그 정책에 따라 처리합니다. Vercel 개인정보 정책 및 연락처
  • Google LLC: Gmail API 메일 전송과 운영자 Gmail 메일함 보관. 문의 목적·이메일·문의 내용·선택 전화번호를 처리합니다. 미국 등 Google의 글로벌 서버에서 처리될 수 있으며 일반 Gmail은 개별 메일의 저장 국가를 고정해서 제공하지 않습니다. 문의 전송 시 HTTPS로 전달하며 운영자 메일함에서는 위 보관·삭제 기준을 적용합니다. Google 개인정보 정책 및 연락처

상담 신청 시 수집·이용 동의와 국외 처리·보관 동의를 각각 받습니다. 동의를 거부하면 웹 상담 폼은 전송되지 않으며 계산기는 계속 사용할 수 있습니다. 전송을 원하지 않으면 폼을 닫아 주세요.

4. 이용자의 권리

개인정보 열람·정정·삭제·처리정지 또는 동의 철회를 위 이메일로 요청할 수 있습니다. 운영자는 요청자 확인 후 처리하고 결과를 안내합니다. 이미 전송한 메일은 상담 창을 닫는 것만으로 삭제되지 않습니다.

5. 보호 조치

상담 요청은 HTTPS로 전송합니다. Gmail 인증 정보는 서버 Secret 환경 변수에만 저장하며 공개 HTML에 넣지 않습니다. 사이트에는 메일 발송 권한만 연결하고 메일 읽기·삭제 권한은 연결하지 않습니다. 상담 전송은 IP별 10분당 3회로 제한합니다. 운영자는 Google 계정 접근을 관리하고 보관 기간이 끝난 메일을 삭제합니다.

6. 쿠키와 브라우저 저장소

계산기와 상담 폼은 입력값을 쿠키·로컬 저장소에 보관하지 않습니다. 상담 창을 닫으면 화면에 입력한 연락처와 문의 내용은 초기화됩니다. 호스팅 플랫폼이 보안을 위해 처리하는 정보는 해당 플랫폼 정책을 확인해 주세요.
