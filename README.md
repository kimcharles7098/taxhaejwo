# TAX해줘

설치 없이 브라우저에서 사용하는 세금·급여 계산기입니다. 네 HTML을 같은 폴더에 두면 왼쪽 메뉴로 이동할 수 있습니다.

| 파일 | 기능 |
| --- | --- |
| `index.html` | 종합소득세 간편 계산 |
| `vat.html` | 부가가치세 계산 |
| `salary.html` | 월급 실수령액 계산 |
| `juhyu.html` | 주휴수당 계산 |

## 사용 방법

저장소를 내려받고 `index.html`을 Chrome 또는 Edge에서 여세요. 각 HTML에 스타일·계산 코드·SUIT 폰트가 포함되어 있어 서버와 인터넷 연결 없이 계산할 수 있습니다. 공식 출처 링크를 누르면 외부 페이지가 열립니다.

## 상담 창

우측 하단의 상담하기 버튼에서 문의 목적, 선택 전화번호, 필수 이메일을 입력하고 내용을 확인할 수 있습니다. **이메일 연결은 보류 중이며 현재 문의가 전송되지 않습니다.** 입력 내용은 외부로 전송·저장하지 않고 창을 닫으면 초기화합니다.

## 계산 기준

2026년 예상 계산용입니다. 종합소득세 경비율 등 일부 값은 예상 가정을 사용하며, 실제 신고·납부액이나 급여명세서와 다를 수 있습니다. 각 계산기의 계산 기준·지원 범위·공식 출처 안내를 확인하세요.
