# TAX해줘

종합소득세, 부가가치세, 월급 실수령액, 주휴수당, 일용근로소득세, 세전 금액 역산 계산기입니다.

- 서비스: https://taxhaejwo.vercel.app/
- 각 HTML에 스타일·폰트·계산 스크립트를 포함합니다. 계산은 브라우저에서 수행하며 금액을 상담 서버로 보내지 않습니다.
- 상담 폼은 목적, 선택 전화번호, 이메일, 문의 내용과 동의를 받아 /api/consult로 전송합니다.
- 서버는 Gmail API로 운영자에게 메일을 보냅니다. Vercel 서버 환경 변수 `CONSULT_RECIPIENT`에 기존 Gmail 발신 계정 겸 고정 수신 주소를 설정합니다. `GMAIL_CLIENT_ID`, `GMAIL_CLIENT_SECRET`, `GMAIL_REFRESH_TOKEN` 및 `CONSULT_ENABLED=true`도 필요합니다. 인증 값은 저장소에 넣지 않습니다.
- 개인정보처리방침: https://taxhaejwo.vercel.app/privacy.html
- 상담 종료 후 30일 이내 운영자가 상담 메일을 직접 삭제합니다.
- 공개 상담 API는 같은 IP에서 10분당 3회로 제한합니다.

계산기는 입력한 가정에 따른 예상값입니다. 2026년 귀속 종합소득세 경비율은 요청에 따른 가정값을 포함하며 실제 신고 전에 공식 기준을 확인해야 합니다. 상담 이메일 발송에는 인터넷과 서버 연결이 필요합니다.

SUIT 폰트 라이선스는 FONT-LICENSE.txt에 있습니다.

세전 금액 역산: `reverse.html` — 희망 세후 월급·연봉과 공제 조건으로 세전 금액을 찾고, 기존 급여 계산식으로 재계산한 세후 금액과 차액을 표시합니다. 기존 `salary.html`의 계산식·세액표를 재사용합니다. 생성·검사 명령과 제한은 `REVERSE-README.md`를 참고하세요.

일용근로소득세: daily.html — 같은 일당×근무일수, 비과세 금액, 일괄/매일 지급, 소득세·지방소득세·세금 차감 후 지급액을 지원합니다. 고용보험 근로자 부담분(선택)을 지원하며 가입 자격과 사업주 부담 보험료는 자동 판정하지 않습니다. 공식 근거와 범위는 DAILY-README.md를 참고하세요.

사업주용 일용직 지급 관리: 근로자 추가·삭제, 지급 월, 근로자별 세금·선택 고용보험 공제·송금액과 전체 합계를 지원합니다. 근로자별로 소액부징수·절사를 적용하고 합산합니다. 입력한 이름·급여를 서버로 보내지 않습니다.
